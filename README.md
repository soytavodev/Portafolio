Portafolio Profesional - Gustavo Delnardo 🚀

Bienvenido al código fuente de mi portafolio personal. Este proyecto no es solo una galería de mis trabajos, sino una demostración técnica de mis habilidades en Frontend Development (UI/UX, CSS 3D, Vanilla JavaScript) y Backend/Arquitectura (reflejada en los proyectos documentados).

🛠️ Stack Tecnológico del Portafolio

HTML5 Semántico: Estructura accesible y limpia.

CSS3 Avanzado: Animaciones, transformaciones 3D (Coverflow Carousel) y diseño responsivo usando variables nativas.

Vanilla JavaScript: Manipulación del DOM y lógica del carrusel sin dependencias externas.

📁 Estructura del Proyecto

```text
/
├── assets/                 # Imágenes, iconos y recursos visuales
├── database/               # (Carpeta para respaldar los esquemas SQL de los proyectos mostrados)
├── index.html              # Landing page principal (Carrusel interactivo + Sobre mí)
├── cv.html                 # Currículum Vitae digital
├── changeit-detail.html    # Detalles del proyecto ChangeIt!
├── duckit-detail.html      # Detalles del proyecto DuckIt!
├── trivia-detail.html      # Detalles del proyecto GuessIt!
├── README.md               # Documentación del repositorio
└── .gitignore              # Archivos y carpetas ignorados por Git
```
