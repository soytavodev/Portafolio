El Reto Técnico

El núcleo de este desarrollo fue dominar el manejo de asincronía y peticiones HTTP. Implementé el consumo de una API REST externa utilizando fetch y Promesas en JavaScript para obtener las tasas de cambio en tiempo real.

El mayor reto fue construir una arquitectura frontend sólida que gestionara los errores de red de forma elegante sin romper la aplicación, optimizando la manipulación del DOM para actualizar la UI instantáneamente. Además, integré un sistema de persistencia en LocalStorage para mantener un historial de conversiones entre sesiones del usuario.
