El Reto Técnico

El desafío central de GuessIt! fue diseñar una arquitectura de backend segura y funcional desde cero. Implementé un sistema de autenticación de usuarios con hashing de contraseñas y gestión de sesiones mediante PHP para proteger las rutas de la aplicación.

A nivel de base de datos, modelé una estructura relacional en MySQL capaz de almacenar perfiles de usuario, gestionar la batería de preguntas y calcular dinámicamente un ranking global basado en el puntaje de las partidas, aplicando sentencias preparadas (Prepared Statements) para garantizar la seguridad contra ataques de inyección SQL.
